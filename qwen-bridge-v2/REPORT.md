# Qwen guest gateway v2 — offline candidate, not live authorization

**Outcome:** The guest listener now uses at most four concurrent handlers, refuses a fifth connection without calling the vendor, and enforces an absolute one-second / 8192-byte header read before checking the task bearer. Authentication happens before reading the body. After authentication, the existing one-operation 60-second deadline (starting at connection handling) covers body read plus bridge/upstream; process-local budgets, fixed route, and no-restart requirement are unchanged. No network/firewall or mount configuration was changed.
